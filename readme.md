🚀 AI Research Assistant (Real-Time)

A real-time AI-powered assistant that can answer questions using live internet data.
Built using LLM agents with tool calling, web search integration, and conversational memory.

Features:
1.Real-time web serach integration.
2.LLM-based intelligent agent.
3.Conversational memory(chat history).
4.Tool calling(dynamic decision making).
5.ChatGPT- like UI using Streamlit.
6.Fast and interactive responses.


🧠 How It Works?
1.User enters a query(question)
2.LLM agent decides - answer directly or call web search tool
3.Web search retrives live data
4.LLM processes results and generated response
5.Chat history is stored for context

Tech Stack:
Python
OpenAI API for LLM
Streamlit for UI
Requests (Web Search API)
Tool Calling - Function calling
